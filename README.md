# AD Bridge Backups

Публичные информационные страницы личного инструмента резервного копирования AD Bridge в Google Drive.

- `index.html` — описание приложения и назначения OAuth-доступа.
- `privacy.html` — политика конфиденциальности.

## Публикация

В Settings → Pages выберите Deploy from a branch, ветку `main` и каталог `/(root)`.

После успешной публикации:

- Главная: https://alexdimkov-ai.github.io/adbridge-backups-info/
- Конфиденциальность: https://alexdimkov-ai.github.io/adbridge-backups-info/privacy.html

Для OAuth используются опубликованные страницы, а не адреса файлов на github.com.

Этот репозиторий содержит только публичные статические страницы. Не добавляйте сюда рабочий код моста, базу, резервные копии, OAuth JSON, токены или пароли.
